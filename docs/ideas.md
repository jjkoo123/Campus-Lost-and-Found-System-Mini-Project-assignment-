## 1. "Help Me Find" request
**Status:** 💡 Idea — to discuss with team (added 04/11/2026)

**What:** A student fills in a form asking the workers (staff/admin) to actively help look for a lost item,
instead of only waiting for it to be handed in.

**Possible fields:** lost report (link to existing Lost Report), urgency (Normal/Urgent),
places already searched, contact time, extra notes.

**Possible flow:**
1. Student opens one of their Lost Reports → "Request help finding"
2. Admin sees the request list → status: Pending → Searching → Found / Not found
3. Student gets a notification when the status changes

**Fits with:** B1 Lost Report (data), B2 Notification (status updates), admin pages.

**Questions for the team:**
- Who owns it? (it is closest to Member B's Lost Report)
- Is it a new module (would break the "exactly 6 modules" rule) or just a status/field on Lost Report?
- Could it be someone's unique feature instead?
- Need tutor approval?
